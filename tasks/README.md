# Task Documents for Claude Code Instances

This folder contains self-contained task documents. Each document is designed
to be given to an individual Claude Code (Haiku) instance to complete independently.

## How to Use

1. Pick a task from `active/` (lower numbers = higher priority)
2. Start a new Claude Code session
3. Paste or reference the task document
4. Follow the instructions in the document
5. When done, the instance will move the file to `archive/`

## Priority Order

- `01-*` through `03-*`: URGENT - Fix broken dog bark detection
- `04-*` through `06-*`: MEDIUM - Code quality and configuration fixes
- `07-*` through `08-*`: LOW - Robustness and future improvements

## Folder Structure

- `active/` - Tasks waiting to be completed
- `archive/` - Completed tasks (for reference)
